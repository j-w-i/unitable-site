Questions

Which universities does it work with?

ANU for now. Unitable is built so other universities can be added, so tell us if you'd like yours next.

Is it made by ANU?

No. Unitable is an independent app made by an ANU student. It isn't affiliated with or endorsed by the Australian National University.

How does it get my timetable?

MyTimetable and Canvas both give every student a private calendar link. You sign in once inside Unitable, it finds those links, and it checks them for changes from then on.

How do I join the beta?

Unitable is on TestFlight, Apple's app for trying apps before they're on the App Store. Tap "Get the beta", install TestFlight, then install Unitable from it.

Is there an Android version?

It's coming. The beta is iPhone first.

What does it cost?

Nothing.
